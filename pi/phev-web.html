Car wifi

Profile car-remote on — · network —

    Changing the network repoints the car profile at a different hotspot. The Pi's registered MAC address stays the same.

    Pairing

    Connect to the car's wifi first. In the car, start Setup Your Vehicle (registration mode), then press Pair. The bridge stops while pairing and restarts afterwards. The car allows a limited number of registrations.

    MQTT broker

    Saved to /etc/phev2mqtt/env, which phev2mqtt and the preheat script read. Save only goes ahead if the login test passes. Changing the prefix also changes the topics Homebridge needs to watch.
